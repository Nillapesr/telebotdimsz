## 🧠 What is TeleForge?

**TeleForge** is a **brutalist**, self-hosted Telegram bot platform built on **Next.js** and **Vercel**. Create, deploy, and manage multiple Telegram bots from a single dashboard — no server management, no hassle.

> _"Forge your bots. Brutally."_

---

## ✨ Features

| Feature | Description |
|:---|:---|
| 🤖 **Multi-Bot Management** | Create and manage unlimited Telegram bots from one account |
| ⚡ **Instant Deploy** | Deploy bots to Vercel with automatic webhook configuration |
| 🧩 **Custom Code** | Write custom JavaScript logic for each bot via built-in editor |
| 📊 **Dashboard** | Brutalist UI with real-time stats and activity logs |
| 🔐 **Authentication** | Secure login/register system with NextAuth.js |
| 🗃️ **Database** | PostgreSQL with Prisma ORM (Vercel/Neon ready) |
| 🎨 **Brutalist Design** | Raw, bold, and functional — no fluff, just power |
